# Engineering Data Science Lab Website

Production repository for the Engineering Data Science Lab website.

This repository is being migrated from the design prototype in `JaeyeongLee1/JaeyeongLee1.github.io/eds-lab-preview` into a maintainable, data-driven site intended for long-term lab ownership.

## Operating principle

- Factual content is stored separately from presentation code.
- Routine updates should not require editing HTML or CSS.
- Professor/member/publication/alumni updates will be manageable through structured data and a CMS.
- AI assistants should follow `AGENTS.md` before changing site content.

## Status

Migration in progress. Do not point `eds.kaist.ac.kr` at this repository until the production checklist is complete.
